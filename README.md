Projects Summary
SQL Analysis of Customer Orders Data
In this project, I used SQLite Online to run SQL queries and analyze a customer orders dataset. 
I explored data by counting total orders, calculating sales, and grouping data by customer and month. 
Additionally, I saved the query results as CSV files for use in Tableau and uploaded both the queries and data files to GitHub for version control.

Customer Data Visualization in Tableau 
Building on SQL Analysis of Customer Orders Data project, this project focused on creating a sales dashboard using Tableau Public. 
I imported CSV files with sales data, created bar and line charts, and combined them into an interactive dashboard. 
The project was saved and published to Tableau Public, and all related work was stored in a GitHub repository.
